Under the hood

The technical rebuild we just shipped

📦→🖥️

WebContainer → real isolated sandbox

We fully removed the old in-browser WebContainer approach (browser-based Node runtime — limited, flaky, capped on real npm/native deps) and replaced it with a real isolated server-side sandbox per site: a full Node/Vite dev server running in its own container, so generated projects behave exactly like a real local dev environment.

🔥

Warm sandbox pool

Pre-booted, pre-baked sandboxes (dependencies already installed) sit ready in a pool so a user isn't waiting on a cold container boot + npm install on every new site.

🔄

Live HMR streaming

As the AI agent writes files, they're streamed straight into the running dev server over hot-module-reload — the preview updates live, file by file, instead of a single build-then-show step.
